# RealOpen Lens 0.1.0

The first stable release of RealOpen Lens: private, offline search and organization
for your photos, screenshots, diagrams and document images, by RealOpen AI.

Lens indexes folders you choose while keeping originals in place. Search by what
an image looks like, words inside it, or metadata such as camera, date and retained
GPS coordinates. No account or cloud inference is required.

## Features

- **Natural-language text search:** combine visual similarity, OCR keywords and
  semantic OCR retrieval. Search error messages, descriptions, identifiers and
  document text in supported languages.
- **Image similarity:** use an indexed image or upload a local query image to find
  similar images. Search a folder, the full library or a virtual collection.
- **Multilingual OCR:** select from 19 bundled languages, with English, French and
  Arabic enabled by default. Recognition runs locally using whole-image Tesseract.
- **Metadata search:** retain EXIF, camera information, capture times and GPS;
  interpret supported natural-language constraints and resolve places offline.
  JPEG, PNG, WebP, BMP, TIFF and HEIC/HEIF files are indexed.
- **Incremental indexing:** resumable jobs, per-file error reporting and stage
  caches reuse compatible metadata, OCR and embeddings. Live progress and
  cancellation are available for long-running tasks.
- **Library browsing:** a timeline with month/day grouping, date ordering and
  scrolling across folders and virtual collections.
- **Image inspection:** zoom, keyboard navigation, OCR text, metadata, source
  locations, feedback and collection membership in the image viewer.
- **Search pagination:** preserve the ordinary first 50 results and load further
  results from a stable pool of up to 1,000 distinct image groups.
- **Folder management:** add folders, refresh indexes, rename folders in Lens and
  remove them from Lens without deleting originals. Optional automatic refresh
  detects changes while Lens is running.
- **Collections and duplicates:** organize manual virtual collections across
  folders, collapse exact duplicates and review near-duplicate suggestions.
  Approximate duplicates are never automatically deleted.
- **Explicit feedback:** label results relevant or irrelevant. Exact-query memory
  can promote or hide those images for that query and scope. Local training,
  evaluation, activation and rollback controls are available for experimental
  learned ranking; labeling does not automatically train or activate a model.
- **Local desktop workspace:** persistent collections, feedback and reviews;
  model setup, download progress/cancellation, light/dark themes and local logs.
  The gallery opens in your browser and communicates with Lens on loopback.

## First launch

1. Open the extracted launcher and review **Device setup**.
2. Choose existing model files or explicitly confirm the pinned model download.
   Internet access is needed for provisioning; indexing and search then work
   offline. Model files are separate from the application archive.
3. Open the image library and choose **Add folder**. Any folder accessible under
   your configured access and OS permissions can be indexed; the repository's
   `data/` directory is not required.
4. Select OCR languages and start indexing. Keep browsing while progress runs.
5. Use **Quit Lens** to stop the local server and workers. Closing the browser
   alone does not stop the launcher.

CPU inference is supported without Docker or a dedicated GPU. New collections
suggest INT8 SigLIP2 below 16 GiB physical RAM and FP32 at 16 GiB or above, with E5
INT8 in both cases. Saved choices and explicit overrides are respected; existing
indexes keep their precision.

## Updating from the alpha

Quit Lens before replacing the application. Keep your existing image folders,
model directory and [workspace](../workspace.md); the application archive and
workspace are separate. If desired, copy the stopped workspace directory as a
backup before updating. Open the new launcher with the same workspace and model
locations. Refresh a folder when its files have changed. Provenance changes can
require recomputing derived stages; compatible stage caches remain reusable.

## Scope and limitations

- The core release uses hybrid ranking and manually selected whole-image
  Tesseract. Optional **automatic script-group OCR**, **learned reranking**,
  **mixed-precision library ranking** and **text-region OCR** remain experimental.
- OCR and retrieval quality vary by language, image quality and content. Bundled
  language availability is not a guarantee of independently reviewed accuracy.
  Short or mixed-script text can confuse automatic detection.
- Searches return ranked candidates, including weak matches. Pagination has a
  1,000-group cap and expiring snapshots. Deeper hybrid results do not use the
  first-page trained reranker; deeper feedback needs separate evaluation before
  training. See [pagination details](../search-pagination.md).
- Location search requires retained GPS metadata; it does not infer a place from
  scenery. Supported natural-language constraints are bounded, not a general
  language-model query parser.
- This is a local, single-user application. Automatic refresh runs while Lens is
  running. PDF, video and audio ingestion are outside this release.
- Native acceptance uses macOS 15 arm64, Windows Server 2022 x64 and Ubuntu 24.04
  x64 runners, including packaged INT8/FP32 inference when enabled. Other OS
  versions, architectures and Linux distributions are not established by those
  checks. Linux needs a browser, fonts and a graphical X11/XWayland desktop.
- A small neural reranker and broader independent relevance review are future
  work. No experimental model is promoted automatically.
